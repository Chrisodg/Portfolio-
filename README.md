# Christopher Odogwu — Professional Portfolio

This is a static, mobile-friendly portfolio created from the information in the supplied CV.

## Files
- `index.html` — portfolio page
- `style.css` — design and responsive layout

## Publish free with GitHub Pages

1. Create/sign in to a GitHub account.
2. Create a new **public repository** named `portfolio` (or `yourusername.github.io`).
3. Upload `index.html` and `style.css`.
4. In the repository, open **Settings → Pages**.
5. Under the deployment/source options, choose the `main` branch and root folder.
6. Save. GitHub will provide the live website address.

A typical address is:
`https://YOUR-GITHUB-USERNAME.github.io/portfolio/`

## Important
The portfolio intentionally does not display the full street address from the CV. A public portfolio should generally use city/state only.
